## What the scorer/eval fix changed

- Trusted exact `User` sender references from fixture message metadata during eval validation.
- Excluded ambient source participants from business-reference accuracy unless explicitly expected.
- Stopped treating missing GROUP, actor, or SEQUENCE output as invented task, cross-assignment, or reversal.
- Preserved real critical detection for explicit invented refs, wrong actor/task swaps, actual sequence reversal, requester/forwarder collapse, and lost conditions.
- Accepted an explicitly retained unresolved condition as safety-preserved even when taxonomy or wording still loses quality points.
- Aligned OpenAI JSON Schema timestamps with the strict runtime contract by using `date-time`.
- Added provider/model metadata and fixed secret redaction so `task-*` identifiers are not corrupted.
